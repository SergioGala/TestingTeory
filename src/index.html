Funciones en JavaScript

Bloques de código reutilizables para organizar tu programación

¿Qué son las funciones?

Las funciones son bloques de código reutilizables que realizan tareas específicas. Son fundamentales para escribir código limpio, modular y mantenible.

¿Por qué usamos funciones?

Imagina que necesitas realizar la misma operación varias veces en tu código. Sin funciones, tendrías que repetir el mismo código una y otra vez:

Sin funciones 
      // Calcular área de un rectángulo (base x altura)
      let base1 = 5;
      let altura1 = 3;
      let area1 = base1 * altura1;
      console.log("El área del rectángulo 1 es: " + area1);
      
      // Ahora calculamos otra área
      let base2 = 7;
      let altura2 = 4;
      let area2 = base2 * altura2;
      console.log("El área del rectángulo 2 es: " + area2);
      
      // Y otra más...
      let base3 = 10;
      let altura3 = 2;
      let area3 = base3 * altura3;
      console.log("El área del rectángulo 3 es: " + area3);
Resultado:
No ejecutado aún

Con funciones, puedes escribir el código una vez y reutilizarlo:

Con funciones 
      // Definimos una función para calcular el área
      function calcularArea(base, altura) {
        return base * altura;
      }
      
      // Ahora podemos usarla muchas veces
      let area1 = calcularArea(5, 3);
      console.log("El área del rectángulo 1 es: " + area1);
      
      let area2 = calcularArea(7, 4);
      console.log("El área del rectángulo 2 es: " + area2);
      
      let area3 = calcularArea(10, 2);
      console.log("El área del rectángulo 3 es: " + area3);
Resultado:
No ejecutado aún

Reutilización

Escribe el código una vez, úsalo muchas veces. Evita repetir las mismas líneas una y otra vez.

Organización

Divide tu código en bloques lógicos que realizan tareas específicas, haciendo que sea más fácil de entender.

Mantenimiento

Cuando necesites cambiar algo, solo debes modificar la función una vez, no cada lugar donde se usa.

Modularidad

Divide problemas grandes en partes más pequeñas y manejables, haciendo que el desarrollo sea más sencillo.

Tipos de Funciones en JavaScript

Declaración de Función

    function saludar(nombre) {
      return "Hola " + nombre;
    }
    
    // Uso
    saludar("Ana");  // "Hola Ana"
  • Se declaran con la palabra clave function
  • Se pueden llamar antes de ser declaradas
  • Fácil de identificar en el código

Expresión de Función

    const sumar = function(a, b) {
      return a + b;
    };
    
    // Uso
    sumar(5, 3);  // 8
  • La función se asigna a una variable
  • No se pueden usar antes de ser declaradas
  • Útil para asignar funciones a eventos o propiedades

Función Flecha

    const multiplicar = (a, b) => a * b;
    
    // Uso
    multiplicar(4, 2);  // 8
    
    // Con múltiples líneas
    const dividir = (a, b) => {
      if (b === 0) {
        return "Error: División por cero";
      }
      return a / b;
    };
  • Sintaxis más corta y moderna (ES6)
  • No tienen su propio this
  • Return implícito en funciones de una sola expresión

Cómo Funcionan las Funciones

ENTRADA

Parámetros que recibe la función

(5, 3)

PROCESO

El código que se ejecuta

return base * altura;

SALIDA

El valor que devuelve

15

Ejecución paso a paso:

1
La función calcularArea recibe 5 y 3 como parámetros
2
Dentro de la función, base vale 5 y altura vale 3
3
Se ejecuta la operación: 5 * 3 = 15
4
La función return devuelve el valor 15
5
La variable area1 recibe el valor 15

Errores Comunes con Funciones

Olvidar el return

// ❌ Error: No retorna nada
function sumar(a, b) {
  a + b;  // Falta return
}

// ✅ Correcto: Con return
function sumar(a, b) {
  return a + b;
}

Sin el return, la función calcula la suma pero no devuelve ningún valor, por lo que siempre obtendrás undefined.

Problemas con this

// ❌ Error: 'this' en función flecha
const persona = {
  nombre: "Juan",
  saludar: () => {
    console.log("Hola, soy " + this.nombre);
  }
};

// ✅ Correcto: Función normal
const persona = {
  nombre: "Juan",
  saludar: function() {
    console.log("Hola, soy " + this.nombre);
  }
};

Las funciones flecha no tienen su propio this, heredan el this del contexto donde se definen.

Buenas Prácticas

  • Usa nombres descriptivos que indiquen lo que hace la función (ej. calcularTotal() en lugar de calc())
  • Cada función debe hacer una sola cosa (principio de responsabilidad única)
  • Valida los parámetros de entrada para evitar errores inesperados
  • Documenta funciones complejas para facilitar su comprensión
  • Mantén las funciones pequeñas y enfocadas (si es muy larga, divídela)
